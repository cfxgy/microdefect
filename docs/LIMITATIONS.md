# 边界与限制

本项目是研究原型，不是量产工业设备。以下限制适用于当前仓库中的代码和结果。

1. **图片上传式检测**：当前通过 Streamlit 上传图片，不是产线实时连续采集。
2. **未完成真实工厂部署**：没有现场相机/光源/工控机参数，也没有产线节拍、PLC 触发和长期运行数据。
3. **不控制机械臂**：不包含分拣、上下料或机械臂控制。
4. **不自动调整相机**：不控制曝光、增益、光源亮度、相机位置。
5. **无 PLC/MES/QMS 接口**：与生产系统的接口尚未开发。
6. **漂移阈值是实验性的**：来自校准图像均值/标准差，不是生产级 FPR 保证；预警只是检查建议。
7. **产品级验证覆盖有限**：演示固定集仅 5+5；需要更多产品、批次和现场样本。
8. **Group-disjoint 仅 4 类单 seed**：不能外推到 15 类，也不能与官方划分直接比较优劣。
9. **NEU-CLS 无分类精度**：只完成数据审计；没有训练/评估结果。
10. **像素级定位未独立验收**：热图/mask 用于人工观察，mask 只是 pixel_threshold 参考。
11. **B 注册在业务演示中由 API 辅助**：不是全部由浏览器完成；文档/报告已如实说明。
12. **更新报告不是密码学签名**：完整性记录用于发现意外修改/错配，不能防止能同时改写所有本地文件的恶意写者。
13. **多进程并发有测试**：重复创建、竞争激活、不同候选竞争已验证；但未做长时间压力/故障注入矩阵。
14. **3D 图是概念设计**：不是实物照片，也不是部署证据。

不能把本仓库的结果表述为：

- 已真实工厂部署；
- 生产级漏报率/误报率保证；
- 对所有工业缺陷都适用；
- 已有机械臂/自动相机/PLC/MES 能力；
- 所有产品/场景的“无遗忘”理论保证。
