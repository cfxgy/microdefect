# 实验与测试

本页只汇总仓库中已实际完成的实验与测试，并明确协议、样本数量和限制。**不是生产性能承诺**。

## 1. NEU-CLS 数据审计

- 1,800 张 BMP，6 类各 300 张，全部 200×200 灰度；
- 无损坏文件；
- 发现 1 组重复图片（Pa_101.bmp 与 Pa_105.bmp）；
- 该数据集不含正常类别，不能单独证明正常/异常检测能力；
- 本项目**未完成** NEU-CLS 分类训练，因此不报告分类准确率。

## 2. MVTec AD 官方划分

- 15 类，5 个 seed，1/3/5-shot；
- 467 正常 + 1,258 异常，1,258 个掩码；
- 图像级使用 `global_full`，像素级使用 `spatial_reference`；
- 阈值来自 calibration 的 0.95/0.99 线性分位，**不是 conformal**。

5-shot 宏平均：

| 指标 | 均值 ± 标准差 |
|---|---:|
| Image AUROC | 0.8494 ± 0.0045 |
| Image AP | 0.9401 ± 0.0019 |
| Image F1 | 0.7605 ± 0.0068 |
| Pixel AUROC | 0.9235 ± 0.0040 |
| Pixel AP | 0.3825 ± 0.0061 |

说明：图像级 `global_full` 在 1/3/5-shot 间成员相同，因此图像级指标相同；这不是重复计算。

## 3. MVTec AD Group-disjoint（B 类近似分组）

- 类别：bottle、pill、toothbrush、zipper；仅 4 类；
- 划分：seed=20261111，τ=0.999 的外观相似连通组；
- 每类 5 张 reference、25 张 calibration；
- 单 seed；不能与官方划分直接比较优劣；不能外推到其余 11 类。

## 4. 产品级演示数据

- 产品 A：正常图 0.012513，异常图 0.048478，阈值 0.021150；
- 产品 B：正常图 0.008028，阈值 0.012758；
- 批量：7 图，5 成功、2 失败，状态 partial；损坏/空文件只影响当前项；
- 漂移：亮度×1.5 窗口 → `drift_warning`，全局 +2.51σ、局部空间 +3.63σ、亮度 +22.74σ、对比度 −21.90σ；
- 更新：v1→v2，独立验证 5+5，verdict=pass；旧 v1 仍可加载；
- A/B 固定集：A v1/v2/注册 B 后 FP=0、FN=0、AUROC=1.0；A 的 173 个文件 SHA 不变。

这些是有限样本上的演示结果，不能外推为所有产品/场景的无遗忘保证。

## 6. 指标解释

- **AUROC**：随机取一个正常、一个异常，异常分数高于正常的概率；1 最好，0.5 接近随机。
- **AP**：不同阈值下 precision 的汇总，适合类别不平衡。
- **F1**：precision 与 recall 的调和平均，依赖具体阈值。
- **FP / FN**：正常误报 / 异常漏报。
- **Pixel AUROC/AP**：像素级热图的排序指标；本项目未完成像素级定位性能的独立验收。
